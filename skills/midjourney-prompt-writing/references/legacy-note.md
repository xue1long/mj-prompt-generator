## 一、实战笔记的改写对照

来源：《Midjourney 情绪版 / 风格参考 / 漂移控制 / 前置图 实战笔记》。该笔记整理自一轮实操对话，文末自注"部分内容由豆包工作 AI 生成"。

### 对照 1 · `--cref` → `--edit`

**原文（三套策略全部使用）：**

```
--cref 角色图链接 --p mxxxxxx --s 200~240 --style raw --ar 9:16 --v 8.2
```

**为什么无效：** `--cref` / `--cw` 是 **V6 / Niji 6 专属**的遗留参数。V7 起由 Omni Reference（`--oref`）取代，**V8.1 起由 Edit Model（`--edit`）取代**。在 V8.2 上写 `--cref` 不会生效。

**V8.2 写法：**

```
--edit https://example.com/char_front.png https://example.com/char_45.png --profile m123456 --s 220 --raw --ar 9:16 --v 8.2
```

**迁移时注意的差异：**

| 项 | `--cref` | `--edit` |
|---|---|---|
| 参考图数量 | 1 张 | 最多 **4 张** |
| 权重控制 | `--cw 0–100`（100 = 只参考脸，0 = 只参考服装气质） | **没有对应刻度** → 靠多传不同角度的图来稳定五官 |
| 版本归属 | V6 / Niji 6 | V8.1+ |
| 附带能力 | 无 | 同时能做局部重绘、扩图、多图融合 |
| 限制 | — | ❌ 与 `--tile` 不兼容；❌ 结果不兼容 Remix |

### 对照 2 · `--style raw` → `--raw`

**原文：**

```
--style raw
```
（笔记里"配套参数"一节写的是"写实/摄影类情绪板必开"）

**为什么无效：** `--style raw` 是 **V5 / V6** 的写法。V7 起官方写法是 `--raw`（Raw 文章原文："Raw is compatible with Midjourney versions 5.1 and later"）。教程《参数全解》与《避坑清单》都把它列为"V7+ 无效"。

**V8.2 写法：** `--raw`

### 对照 3 · `--p` + `--sw` 同现

**原文（策略 B）：**

```
--cref 角色链接 --p mxxxxxx --sref https://质感参考图.jpg --sw 80~120 --s 200 --style raw --ar 9:16 --v8.2
```

**为什么无效：** 官方 Style Reference 页原文 "--sw is not compatible with Moodboards"；Moodboards 页同样写明不能与 `--sw` / `--sv` 同用。**情绪板与 `--sw` 二选一。**

**V8.2 写法（两条路）：**

```
/* 路 1：保留情绪板，去掉 --sw（--sref 单独出现时权重取默认 100） */
--edit https://example.com/char_front.png --profile m123456 --sref https://example.com/texture.jpg --ar 9:16 --v 8.2

/* 路 2：放弃情绪板，单独用 --sw 控制质感 */
--edit https://example.com/char_front.png --sref https://example.com/texture.jpg --sw 110 --ar 9:16 --v 8.2
```

### 对照 4 · `--iw` 取值范围

**原文（4.4 节表格）：** "`--iw` 区间 0.3–0.6 / 0.8–1.0 / 1.2–2.0"，并写"默认 1，范围 0–2"。

**为什么无效：** 官方 Image Prompts 页——**V8.1 与 V7 是 0–3，Niji 7 才是 0–2**。原文把 Niji 7 的范围当成了通用范围。

**V8.2 写法：** 短剧主线仍推荐 0.3–0.6（这是用法建议，与取值范围无关），但**上限是 3**，不是 2。

---

### 对照 5 · `--s` 的两套含义

**原文（1.4 节）：** "`--s`（stylize）：直接影响情绪板权重。50–100 弱跟随、200–400 平衡、600–1000 强跟随"。

**问题：** `--s` 的**官方**定义只有一个——风格化强度（数值越高越不贴字面，0–1000，默认 100）。原文那套阶梯描述的是**情绪板跟随度**，即情绪板对画面的控制强度，**不是官方参数语义，属社区观察**。

**处理：** 术语表把两者拆开——`--s` 只指风格化强度；情绪板跟随度另立一词并标注"社区经验"。两套阶梯都可以用，但**别用 `--s` 指代后者**。

---

### 对照 6 · 情绪板档案的调用写法

**原文：** "点 Use in Prompt 拿到情绪板 ID，调用方式：`--p m123456`"。

**问题：** 官方文档记载的是 `--p`（调用默认档案）与 `--profile [code]`（指定档案）。行内写成 `--p <id>` 是社区流传的简写形式。

**V8.2 写法：** `--profile m123456`（指定具体档案）/ `--p`（调用默认档案）。多个档案可 `--profile m1 m2`。

---

### 对照 7 · 提示词正文用中文

**原文：** 全篇用中文长句作提示词，如 `年轻东亚女生，坐在窗边看书，侧脸，柔和自然光`。

**问题：** 教程《常见误区》指出：中文长句提示词"能用但理解精度低于英文，关键风格词建议用英文"。

**处理：** 本技能统一**英文提示词正文 + 中文讲解**。中文写法可用，但正式交付时把提示词正文换成英文；中文描述可作为补充角色（MJ 能读），但风格词必须是英文。

## 二、教程《附录 A 速查卡》的两处笔误

原始速查卡与官方口径不符，本技能采用官方口径：

| 项 | 附录 A 速查卡 | 官方口径 | 本技能采用 |
|---|---|---|---|
| `--weird` | `0-2000` | **0–3000** | 0–3000 |
| `--iw` | `0-2` | **V7/V8.1 为 0–3**，Niji 7 为 0–2 | 0–3（标注 Niji 7 为 0–2） |
