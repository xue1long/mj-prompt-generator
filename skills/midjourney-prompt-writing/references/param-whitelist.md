# V8.2 参数白名单与组合规则

> **本文件只回答两个问题：某个参数能不能写进 V8.2 提示词？两个参数能不能同时写？**
> **取值的精确范围、官方出处、废弃状态 → 加载 `midjourney-doc-facts` 技能。** 本文件不复制那份表。
> 取用日期：2026-11-03 ｜ 版本基线：V8.2（官方 2026-07-24 起的默认版本）

---

## 一、版本决策路径

写提示词前先定版本。**选错版本，参数会被静默忽略或整单回退到旧版渲染。**

```
需要 --cref 角色参考？          → --v 6.1 或 --niji 6
需要 :: 多提示词权重？          → --v 6.1
需要 --q 质量档位？             → --v 7
需要 --oref 全能参考？          → --v 7
需要 Draft 24 张草图？          → 网页端 + --v 8.2（默认，不写版本号即是）
需要 Edit Model / --p / --hd / 最佳文字？ → --v 8.2（默认）
做动漫？                       → --niji 7（要风格预设则 --niji 6）
```

**默认就是 `--v 8.2`。** 回退版本是例外，不是常态。

## 四、组合冲突（最容易踩）

| 规则 | 后果 |
|---|---|
| `--v` 与 `--niji` 互斥 | 只能写一个 |
| `--raw` 对 Niji 无效 | Niji 有自己的 `--style` 预设体系 |
| `--sw` / `--sv` 与 **Moodboards（`--p`）** 不兼容 | 用情绪板就别写这两个 |
| `--tile` 与 `--edit` 不兼容 | 同时写会报错 |
| `--edit` 的结果**不兼容 Remix** | V8.2 想用 Remix 迭代 → 改用 V7 及更早 |
| `--oref` 与 Draft / Fast / Conversational 不兼容 | 且与 `--q 4`、Vary Region、Pan、Zoom Out 不兼容；GPU 成本 2 倍 |
| `--sref random` 只兼容 `--sv 4` 和 `--sv 6` | 写 `--sv 5` + `random` 无效 |
| **HD 图上做 Pan / Zoom Out / Vary Region → 结果降回 SD** | 先扩图，最后一步再上 `--hd` |
| **Vary Region 在 V8.2 上仍是 V6.1 引擎，且只作用于 V8.2 的 SD 图** | 要编辑 HD 图得用 midjourney.com 的 Edit 工具，结果仍是 SD |
| 参数必须**全部在末尾** | 夹杂在提示词中间会解析失败 |
| 所有标点用**英文半角** | `：` `，` `（）` 都会导致失败 |

### `--no` 的审核陷阱

官方特别警告：审核系统会**逐词独立**读取 `--no` 里的每个词。

写 `--no modern clothing` 会被理解成"不要现代" + "不要衣服"，可能误触发审核警告。

→ **遇到这类情况，在提示词正文里写明你要的服装类型，而不是用 `--no` 排除。**

## 五、一页速查卡（修正版）

```
【版本】--v 8.2(默认)  8.1  7  6.1  |  --niji 7  6      ← 只能二选一
【比例】--ar 16:9 21:9 4:5 6:11 9:16 1:1 3:2 2:3        (最大 14:1, HD 4:1)
【风格】--s 0-1000(默认100)  --c 0-100  --exp 0-100(甜区10-25,社区实测)  --weird 0-3000
【减法】--no anime, cartoon, illustration, painting
【写实】--raw   ← 不是 --style raw
【复现】--seed 整数   ← V8 为 99% 相同
【参考】--edit 最多4图(V8.2主力)  --sref+--sw(V6+)  --oref+--ow(V7)  --cref+--cw(V6/Niji6)
【垫图】--iw 0-3(默认1, Niji7 为 0-2)
【画质】--hd 2048px(1.3 GPU 分)  --sd(0.8 GPU 分)  --draft 24张(仅网页端)
【个性化】--p  --profile [code]
【失效】--q(V8)  ::(V7+)  --style raw(V7+)  --v 8  --preview(不存在)
      /tune(已失效)  /prefer option delete(该命令不存在)
```

> ⚠️ **速查卡纠错记录**：原始教程《附录 A》的速查卡把 `--weird` 写成 `0-2000`、把 `--iw` 写成 `0-2`——两处都与官方口径不符。官方 `--weird` 是 **0–3000**，`--iw` 在 V7/V8.1 是 **0–3**（只有 Niji 7 是 0–2）。本技能采用官方口径。

## 六、症状 → 正确做法

| 症状 | 原因 | 正确做法 |
|---|---|---|
| 参数被静默忽略 | 写了 V8.2 不支持的参数 | 对照上面的白名单 |
| 整单画风变老 | 用了 `--oref` 却没指定版本 → 回退 V7 渲染 | 改 `--edit`，或显式 `--v 7` |
| 画面里总有卡通感 | 没排除 | `--no anime, cartoon, illustration, painting` |
| 人物脸每次都变 | 靠 `--seed` 锁不住 | 用 `--edit` 传角色图（见 `drift-control.md`） |
| 扩图后分辨率掉了 | 在 HD 图上做的编辑 | 先扩图，最后一步再 `--hd` |
| 局部重绘没反应 | 选区太小 | 选区占画面 20%–50% |
| 审核莫名被拦 | `--no` 里的词被逐词独立读取 | 改成在正文里写明要什么 |
| 出图文字拼错 | MJ 不保证拼写 | 关键文字后期合成 |

## 七、官方文档自身的矛盾

已登记 3 条（Draft 在 V8 是否支持、当前默认版本、HD 编辑降级），裁决顺序与详情见 `midjourney-doc-facts` 的 `references/param-source-map.md`。

**本技能采用的口径：**

1. Draft 在 V8.1/V8.2 **支持**，但**仅网页端**
2. 当前默认版本是 **V8.2**（不是 Legacy Features 页上写的 V7——那页更新日期早于 V8.2 发布）
3. HD 图上的 inpainting/outpainting 结果**降到 SD**（记为已知限制，非矛盾）
