# 短剧 / 漫剧批量出图：角色一致性与漂移控制

> 来源：《Midjourney 情绪版 / 风格参考 / 漂移控制 / 前置图 实战笔记》，**按 V8.2 官方口径改写**。
> **原笔记的三套策略全部使用 `--cref`，而 `--cref` 在 V7 起已被取代、V8.1 起由 Edit Model 取代——三条策略在 V8.2 下全部无效。** 本文件是改写后的版本；原文与失效原因对照见 `legacy-note.md`。
> 目标：**人脸稳定、光影色调统一、镜头动作可变、长期批量出图不跑偏。**

## 一、情绪板档案（`--p` / Moodboard）

情绪板是 MJ 网页端「Personalization → Moodboards」里的**长期风格档案**，用来锁定一套固定美学（色调、光影、质感、笔触、氛围），适合长期统一画风、短剧人设、品牌视觉、系列插画。

### 1.1 操作流程

1. 网页端左侧 → **Personalization → Moodboards → New Moodboard**
2. 三种加图方式：本地上传 / 链接添加 / 从自己 MJ 作品库添加
3. 命名分类（如：短剧女主冷白皮、日系胶片、暗调油画）
4. 点 **Use in Prompt** 拿到情绪板 ID，调用时写进提示词

```
/imagine a young woman standing by the sea --profile m123456 --v 8.2
```

| 写法 | 含义 |
|---|---|
| `--p` | 调用**默认**情绪板 |
| `--profile <code>` | 指定某个具体档案（**官方文档写法**） |
| `--p m123456` | 社区流传的行内简写；**官方文档记载的是 `--profile [code]`**，优先用后者 |
| `--p mID1 mID2` | 多板混合 |

> 设置里可开启全局自动携带，所有生成自动套用。
> ⚠️ **必须先解锁 Global Profile**，否则用 `--p` / `--profile` 会直接报错（通过 Personalize 页面选够喜欢的图来解锁）。
> ⚠️ **`--sw` / `--sv` 与 Moodboards 不兼容** —— 用情绪板时不要写这两个参数。

### 1.2 选图黄金规则

| 规则 | 具体要求 |
|---|---|
| **数量** | 3–8 张最优；3–5 张风格极强、6–10 张同色系给 AI 更多变化；不要几十张风格冲突图混放 |
| **统一维度** | 同板内统一色调、光影逻辑、质感；不要一张赛博朋克、一张水墨、一张复古胶片混放 |
| **学感觉不学内容** | 优先选光影、色彩、质感参考，而不是特定角色/物体 |
| **迭代提纯** | 生成满意的图回加到情绪板，越用越稳；崩坏图绝对不要进板 |
| **人像配额** | 板内 4–6 张时，人像参考控制在 **2 张以内**，其余放空镜、材质、光影 |

### 1.3 提示词与参数分工

**核心分工：情绪板负责风格氛围；文字提示词只负责内容、主体、动作、场景。**
不要在提示词里堆风格形容词（`soft cinematic`、`film grain`、`muted color`……），会和情绪板打架。

```
/imagine a young east asian woman, sitting by a window reading, side profile, soft natural light --profile m123456 --ar 9:16 --s 250
```

### 1.4 配套参数

| 参数 | 作用 |
|---|---|
| `--s`（stylize） | 数值越高，模型越倾向于按自己的审美演绎。**社区观察到**：情绪板存在时，50–100 弱跟随提示词、200–400 平衡、600–1000 强跟随情绪板 —— ⚠️ 这是**社区经验，不是官方参数语义**，官方只定义了 `--s` = 风格化强度 |
| `--raw` | 写实/摄影类情绪板建议开，降低 MJ 自带滤镜，光影色彩更干净（⚠️ V7+ 用 `--raw`，不是 `--style raw`） |
| `--no` | 干掉情绪板里带出来的讨厌元素，如 `--no grain` |

## 二、`--p` 情绪板 vs `--sref` 风格参考

一句话：**`--p` 是长期风格档案、一套美学体系；`--sref` 是单次临时借一张/几张图的画风。**

| 维度 | `--p` 情绪板 | `--sref` 风格参考 |
|---|---|---|
| **本质** | 网页端预先建好的风格库档案，多张精选图 | 直接在 prompt 里贴图片链接，单次即时调用 |
| **存储** | 保存在账号里，有固定 ID，随时复用 | 不保存，这条指令跑完就失效 |
| **强度调节** | 用 `--s` 控制（**社区经验**） | 用 `--sw` 控制 |
| **作用逻辑** | 学习整套氛围、美学倾向、光影逻辑，包容性强 | 精准复刻参考图本身的笔触、配色、质感，更贴原图 |
| **适合场景** | 短剧、连载漫画、IP 系列、品牌长期统一画风 | 临时模仿某张图画风、试新风格、单次效果图 |
| **混合** | `--profile m1 m2` | `--sref url1 url2` |
| **兼容性** | ⚠️ **不能和 `--sw` / `--sv` 一起用** | 支持 `--sv` 版本切换 |

**通俗比喻：** `--p` 是你提前整理好的一本美术规范画册，整部剧所有镜头都按它画；`--sref` 是你随手递给画师一张参考图，"就按这张质感画这个新东西"，用完就丢。

**补充区分：**

| 写法 | 作用 |
|---|---|
| 图链接直接放最前面（不带参数） | **图像提示**（垫图），优先学构图、主体、姿态 |
| `--edit URL` | **编辑模型参考**，V8.2 锁角色长相/多图融合的主力（V7+ 取代了 `--cref`） |
| `--sref URL` | **风格参考**，只学画风 |

## 三、漂移控制

### 3.1 底层分工（V8.2）

| 手段 | 锁什么 |
|---|---|
| `--edit` | **角色五官长相**（核心防脸崩）——V8.2 取代了 `--cref` |
| `--profile` / `--p` | **整套美术氛围、光影、色调、质感**（长期基准） |
| `--sref` | 临时叠加质感/笔触，**不适合长期固定主线** |
| **图像提示（垫图）** | 构图、姿态、镜头，慎用 |

### 3.2 三套固定策略

#### 策略 A：主线稳定出图（首选，覆盖 90% 镜头）

**组合：`--edit` + `--profile`，不带 `--sref`**

```
/imagine a young east asian woman, holding an umbrella, walking in a rain-soaked alley at night, glancing back over her shoulder, story mood, soft diffuse ambient light --edit https://example.com/char_front.png https://example.com/char_45.png --profile m123456 --s 220 --raw --ar 9:16 --v 8.2
```

- 动作复杂 / 多人 / 大场景 → `--s` 降到 140–190，优先保结构
- 特写 / 氛围感镜头 → `--s` 拉到 250–280
- 情绪板固定版本，不要天天加图；迭代版新建板（m01、m02），旧板封存
- 板内 4–6 张，人像参考控制在 2 张以内，其余放空镜、材质、光影
- **锁脸靠多角度图**：`--edit` 没有 `--cw` 那样的权重刻度，多传正面 + 标准 45° 侧面的图更稳

#### 策略 B：特殊镜头叠加质感（回忆 / 梦境 / 闪回）

**组合：`--edit` + `--profile` + `--sref`（不带 `--sw`）**

```
/imagine the same woman with eyes closed, hazy memory shot, shallow depth of field --edit https://example.com/char_front.png --profile m123456 --sref https://example.com/texture.jpg --ar 9:16 --v 8.2
```

**硬性约束：**

1. ⚠️ **带了 `--profile` 就不能写 `--sw` / `--sv`**（官方不兼容）
2. 想要更强的质感控制 → **这条镜头放弃 `--profile`**，改用 `--sref URL --sw 100~120` 单独控制
3. 这组跑完，下一组立刻删掉 `--sref`
4. sref 图尽量选无人物、只有材质光影的图，不要放别人的人像

#### 策略 C：试新风格、对标参考（纯测试）

**组合：`--edit` + `--sref`，不用 `--profile`**

```
/imagine a woman, backlit silhouette by a window --edit https://example.com/char_front.png --sref https://example.com/style.jpg --sw 150 --ar 9:16 --v 8.2
```

跑出来满意后，**把成品筛选加入情绪板，转为策略 A 长期方案**，不要一直用 sref 跑主线。

### 3.3 四大漂移源头与修复

| 漂移类型 | 原因 | 修复手段 |
|---|---|---|
| **人脸漂移** | 参考图角度杂乱；权重不足；sref 过强 | `--edit` 传正面 + 标准 45° 侧面多张；情绪板人像 ≤2 张；叠加 sref 时别带 `--profile`；崩脸就去掉 sref |
| **色调漂移** | 情绪板内图片色彩冲突；提示词反复加矛盾色彩词 | 情绪板白平衡统一；删掉提示词里冗余风格词；用 `--no yellow` / `--no blue` 压制色偏 |
| **结构漂移** | `--s` 太高；情绪板里大量强构图图；前置图太多 | 复杂动作镜头 `--s` 压到 140–180；情绪板少放特殊透视图；前置图不要和高 `--s`、高 `--sw` 叠加 |
| **风格越跑越歪** | 反复往情绪板加新产出、版本不隔离 | 版本管理 m01/m02，旧板封存；每轮只挑 3–5 张最稳定成品新建板；固定 prompt + seed 做对照 |

### 3.4 优先级与黑名单

**权重优先级：**

```
角色长相(--edit) > 构图姿态(前置图) > 单次质感(--sref) > 整体氛围(--profile/--p)
```

**禁止搭配：**

- ❌ `--profile` + `--sref` + 前置构图图 + 高 `--s` + 高 `--sw` 一起堆
- ❌ 主线批量镜头常驻 `--sref`
- ❌ 情绪板放十几张杂乱不同风格的图
- ❌ 用画风参考图（网红人像）直接当角色参考图

## 四、前置图（垫图 / 图像提示）

前置图放在整段提示词最开头，优先学：**构图、机位、姿态、画面空间关系**。它也会顺带带色调和长相，所以短剧里是高风险工具，**只用来锁镜头构图，不要拿来当画风/角色参考**。用 `--iw` 控制前置图权重。

### 4.1 怎么拿到可用链接

| 方式 | 操作要点 |
|---|---|
| **MJ 网页端（推荐）** | midjourney.com/create → 输入框左边图片图标上传 → 自动变成前置图链接直接加入 prompt；在 Manage Uploads 里管理所有上传图 |
| **Discord 上传** | 点 `+` 号上传图片发送 → 点开大图 → 右键复制图像链接；后缀必须是 `.jpg`/`.jpeg`/`.png`/`.webp`，不能是消息页面链接 |
| **第三方图床** | imgur、postimage 等；缺点是链接易失效，批量短剧不建议 |

### 4.2 去哪里找适合的前置图

**核心原则：优先找机位、构图、人体姿态、镜头景别；原图的人脸、服装、色调全部不重要。**
理想前置图 = 线稿、人体动态速写、空镜分镜、剪影、姿势参考；尽量不要带清晰好看的真人脸。

1. **自己之前 MJ 产出的合格分镜（首选，版权安全）** —— 上一组合格镜头下载裁剪成目标比例，作为下一组同机位前置图
2. **人体姿势库、速写站、PoseLib（只拿动态）** —— 搜 `cinematic pose reference`、`storyboard sketch`、`film shot reference`、`silhouette pose`；优先黑白线稿、剪影、无五官
3. **电影截图 / 影视剧分镜（谨慎，版权风险）** —— 只学机位（过肩、低角度仰拍、框架构图、前景遮挡）；不要直接大量商用
4. **Pexels、Unsplash 免费商用摄影图** —— 搜 `cinematic composition`、`over the shoulder shot`；找空镜、背影、侧影，避开清晰正面人脸

### 4.3 选图标准

- **比例对齐** —— 前置图裁剪成和最终画面一样比例（短剧 9:16），AI 理解构图最准
- **画面信息极简** —— 只保留主体位置、肢体姿态、前景/后景结构；花哨光影、配色、复杂服装去掉
- **一张最优** —— 最多不超过 2 张；多张前置图构图打架概率极高
- **主体数量匹配** —— 前置图 1 个人，prompt 就写 1 个人；前置图双人就写双人

### 4.4 `--iw` 权重控制

> `--iw` 在 V7/V8.1 的官方范围是 **0–3**（默认 1）；只有 Niji 7 是 0–2。

| `--iw` 区间 | 效果与使用场景 |
|---|---|
| **0.3–0.6** | **短剧主线最常用**：只借构图机位，姿态大致跟随，不抢角色脸、不抢情绪板氛围，最稳 |
| **0.8–1.0** | 强跟随构图，姿态、透视贴近参考；适合严格固定机位对话镜头 |
| **1.2–2.0** | 高权重，风险很大，容易把前置图的脸、颜色、服装吃进来；主线尽量不用 |
| **3** | V7/V8.1 上限；仅在需要极端贴合构图时使用 |

```
/imagine [前置构图链接] a young woman in the rain, side glance, dialogue shot --edit https://example.com/char_front.png --profile m123456 --iw 0.5 --s 220 --raw --ar 9:16 --v 8.2
```

### 4.5 冲突避坑清单

- ❌ 高 `--iw` + `--sref` 高 `--sw` + `--profile` 一起堆，多重参考互相打架
- ❌ 前置图是带清晰人脸的真人图，再叠加角色参考图，两个脸互相竞争
- ❌ 前置图里的光影、色调和情绪板完全相反
- ✅ **正确分工**：前置图锁机位构图（低 `--iw`）、`--edit` 锁长相、`--profile` 锁光影色调、`--sref` 临时叠特殊质感（主线不带）

## 五、出图前快速自检 SOP

每次出图前对照检查：

1. **本次是主线镜头？** → 只用 `--edit` + `--profile`，去掉 `--sref`
2. **是特殊效果镜头？** → 加 `--sref`，**且不写 `--sw` / `--sv`**；跑完立刻取消
3. **情绪板是否统一光影色调？** 人像是不是少量、角度接近？
4. **动作复杂** → `--s` 压低；**特写氛围** → `--s` 拉高；叠加 sref 时 `--s` 不超过 220
5. **提示词只写主体、动作、场景、打光描述**，不堆风格形容词
6. **前置图**：是用来锁构图不是学画风？有没有清晰正面人脸？比例和 `--ar` 一致？`--iw` 是否压到 0.3–0.6？
7. **参数检查**：有没有 `--cref` / `--style raw` / `--q` / `::` / `--v 8`？有没有 `--sw` 与 `--profile` 同现？标点是不是全英文半角？
