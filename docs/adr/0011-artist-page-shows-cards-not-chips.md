# 艺术家页用卡片网格，不用标签云

「艺术家/摄影师」分类有 4300 多条：23 条手写词条 + 4300 条风格条目。过去它们和其他五个分类一样渲染成标签云（每个词条一枚小标签），于是有两个问题：看不见样例——4300 条里每条一张上游样例图，却一张都不显示；分不清是谁——风格条目没有中文名，标签上只有原文名，"Alan Fearnley" 和 "William Tillyer" 并排时无从判断。

决定：**只有艺术家页改成卡片网格**（1:1 预览图 + 常驻信息区 + 角标 + 按钮组），其他分类保持标签云不动。

## 考虑过的选项

- 全部六个分类一起改卡片：会把一次改动摊到六个页签上，风险与评审成本都不成比例；而其余五个分类加起来不到 200 条，标签云完全够用。
- 给艺术家页做一个"类目"筛选维度，把分组拍平成一格：既推翻了既有决策（类目已经是二级分类，硬造一个类目筛选器只是多一层冗余，见 `docs/风格库筛选方案.md`），也让筛选条更挤。
- 卡片上放中文名：上游不给中文名，本仓没有翻译词表，4300 条一次性翻译出来的结果无人校对、也无人维护。改用上游自己给的一句话简介（见 ADR-0012）。

## 后果

- 分组保留：仍是 17 个二级分类，组标题 + 组内网格。分组是这一页唯一的"按类目浏览"入口，拍平就永久丢了。
- 主路径是"选一个风格"，所以单击卡片即选中/取消，详情另开弹窗（点击不与选中冲突）；卡上另有一个「Midlibrary ↗」逐条回链——这是站方许可的履行方式（见 `NOTICE.md`），不是可选项。
- 角标位放主色色块与「实测」标：风格参考码的角标放的是码本身，风格条目没有码，分类名又已在组标题上。
- 筛选条改为吸顶：4000 多条要滚很久，改筛选条件时手不用往回挪。
- 每组仍按 100 条一批分页，但**筛选条件一变就回到第一页**（旧实现筛选后分页不重置，会停在空白的第 N 页上）。
