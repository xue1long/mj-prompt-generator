# 对照视图作为独立一级视图

> **状态**：accepted（2026-11-10）
> **决策来源**：《第一性原理校验报告》2.2 节 + grilling 第 8 步 AskUserQuestion 用户拍板（「对照视图形态」→ 独立一级视图）。
> **配套**：`docs/adr/0020-research-sample-library-is-top-level.md`（一级视图标准，本 ADR 是它的**第一个例外**）、`docs/adr/0017-static-webui-replaces-vue-spa.md` Round 15（实施编年）、`docs/第一性原理校验报告.md` 2.2 节「修法与验证」。

## 决定

「对照」成为工作台的**第 4 个一级视图**，与提示词库 / 研究样本库 / 研究笔记并列。

```
一级视图（VIEWS，4 个）
├── 提示词库    library     可拼装的片段 —— 你的假设集
├── 研究样本库  samples     社区已做好的成品 —— 证据集
├── 对照        compare     并排看两条 —— 固定变量再下结论
└── 研究笔记    research    观察记录与结论
```

URL 形态：`#compare?a=<引用键>&b=<引用键>`。

## 为什么难逆转

- 它是本项目**第一个打破 ADR-0020 一级视图标准的视图**。标准一旦可以按例外突破，标准本身就不再是标准 —— 所以这条理由必须留在 ADR 里，而不是只留在代码注释里。
- 对照对象用**引用键**（第 5 步的 `<id8>-<hash4>`）而非内部 UUID，粘给同事即可复现。URL 形态一旦发布就是对外契约。

## 这是一个例外，而不是标准

ADR-0020 定下的一级视图标准是「**异质的数据集**」：

| 一级视图 | 数据集 | 同质？ |
| --- | --- | --- |
| 提示词库 | 可拼装的片段（假设集） | ✅ 与其它不同类 |
| 研究样本库 | 不可拼装的成品（证据集） | ✅ 与其它不同类 |
| 研究笔记 | 我自己的产出 | ✅ 与其它不同类 |
| **对照** | **研究样本库里的两条** | ❌ **与研究样本库同源** |

对照视图装的是样本库里的两条作业，**数据同源** —— 按 ADR-0020 的标准它不满足一级视图的资格。

但它仍然要独立，理由是**它是一类动作，不是一类数据**：

| 理由 | 说明 |
| --- | --- |
| **需要并排的空间** | 两列布局。样本库是卡片流，塞不下也看不清 —— 强行塞进卡片流就没有「对照」可言 |
| **需要 URL 可分享** | 粘给同事，对方直接看到同一组对照。这是研究动作的属性，不是数据集的属性 |
| **需要固定的比较对象** | `a` / `b` 两条是**钉死的**；样本库是滚动中的列表，没有「当前这一条」的概念 |
| **需要独立的读法** | 对照页读的是「差异」（措辞差异 / 元数据不同项 / 拆解不同段），样本库读的是「条目」—— 两种读法不能塞进同一套卡片模板 |

## 考虑过的选项

| 选项 | 否决理由 |
| --- | --- |
| **样本库下的二级页签** | 样本库是卡片流，卡片流没有并排语义；且页签意味着「样本库的一个子集视图」，而对照是**跨样本的动作** |
| **灯箱里的「对比」按钮**（在灯箱内并排） | 灯箱一次只看一条。对照需要**同时**看到两条的成图、措辞、元数据、拆解 —— 塞进灯箱会让灯箱承担两种完全不同的读法 |
| **纯 URL 形态**（不进视图导航，只靠地址栏） | 研究者不会为了对照去手改地址栏。这条路径「能实现」但「不会被用」—— 不可用性会让功能等于不存在 |
| **独立的第二个应用** | 对照对象来自样本库，独立应用会切断两者之间的引用关系（引用键要跨应用传递） |

## 后果

- **`CONTEXT.md` 新增「对照视图」术语**，明确它是**动作型视图**（action view）而非数据集型视图。
- **ADR-0020 的一级视图标准要补一句例外说明** —— 标准本身仍然有效（三个数据集型视图都满足），但要承认「动作型视图」是另一类东西。
- **对照的 URL 只带 `a` / `b`，不带样本库的筛选参数**。取舍：对照的是两条已固定的作业，筛选条件对它们没有意义；而样本库那边的筛选状态本来就独立保存在自己的 hash 里，切回去时各自恢复，互不污染。
- **`workbench.js` 的 `readHash()` 要为对照视图开白名单** —— `a` / `b` 是引用键不是筛选维度，否则 `#compare?a=…&b=…` 会被当「不支持的参数」丢掉，对照链接直接失效。
- **切视图必须用 `location.hash =` 而不是 `history.replaceState`** —— `replaceState` 不触发 `hashchange`，`readHash()` 就不会跑，`ui.view` 停在样本库，页面看起来「地址栏变了但内容没变」（本轮实际踩过）。
- **一级视图计数要动态化** —— 对照的计数是 0 / 1 / 2（有对象时是 2），与其它三个视图的计数口径不同。

## 明确不做的事

- **不做跨作业的统计对比** —— 对照是**两条**的并排比较。「这批样本里 X% 用了暖色调」这类横向统计属第 10 步（本地数据层）。
- **不做三方以上对照** —— 两列是并排阅读的上限；三列在 1440px 宽下每列只剩 480px，措辞差异会被压到读不下去。
- **不保留对照历史** —— 对照是即席动作，不是资产。要留结论就写进研究笔记（第 6 步的结论实体），它本来就支持挂多条依据样本。
