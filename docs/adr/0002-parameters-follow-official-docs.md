# 参数面板以官方文档为唯一事实基准

上游的 `parameters.yaml` 存在多处事实性错误：`--q` 提供了官方从未有过的 `0.25` 取值且在 V8.1/V8.2 已被官方取消、`--iw` 上限写成 2（官方 V7/V8.1 为 0–3）、`--style raw` 写法已废弃、`--style original` 属 V1–V4 时代遗留、`--cref` 已是 Legacy 功能、`--stop` 在官方现行参数表里根本不存在（上游代码里有分支但 YAML 无配置项，永不生效）。决定以 Midjourney 官方帮助中心（取用日期 2026-11-03）为唯一事实基准重写参数配置，并交付带出处的《参数事实表》。

## 考虑过的选项

- 保持与上游一致：等于继续让工具产出无效提示词，且用户无从判断。
- 依赖社区经验值：没有出处，无法核验，也不符合本项目"结论必须挂到出处"的要求。

## 后果

- 参数数量从 13 增至 24，覆盖官方现行图片类参数。
- 官方文档自身的矛盾（Draft 在 V8 是否支持、当前默认版本）必须显式登记，不能静默选一个。
- 上游若更新参数，需要按官方文档复核，而不是直接覆盖本项目的事实表。
