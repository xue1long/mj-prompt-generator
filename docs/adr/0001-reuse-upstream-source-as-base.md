# 以 MIT 上游源码作为底座

本项目需要一个本地运行的 Midjourney 提示词生成器。上游 `xueshanlinghu/MJPromptGenerator`（MIT）已提供完整的 Vue 3 + Naive UI 实现、156 条摄影提示词词库与 156 张预览图，因此决定直接以该源码为底座本地化，保留 MIT LICENSE 与原 README 中"野菩萨老师及其团队"的致谢，并删除其 GitHub Pages 部署工作流。

## 考虑过的选项

- 从零重写：会丢弃已有词库与预览图，且重写出来的界面短期内不会更好用。
- 只抄数据自研：仍需重建全部界面逻辑，属于重复劳动。

## 后果

- 界面改动受上游组件结构约束（`src/components/` 下的既有划分）。
- 上游若有新版本，需要按官方文档复核参数部分，而不是直接覆盖。
