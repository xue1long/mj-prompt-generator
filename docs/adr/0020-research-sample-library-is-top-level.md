# 研究样本库升为一级视图

> **状态**：accepted（2026-11-10）
> **决策来源**：《第一性原理校验报告》4.2 节 + grilling 第 1 轮 Q3 裁决 + 第 7 步实施。
> **配套**：`docs/adr/0019-prompt-research-workbench-positioning.md`（定位转型）、`docs/adr/0017-static-webui-replaces-vue-spa.md` Round 14（实施编年）、`docs/adr/0013-explore-board-is-its-own-page-collected-daily.md`（被本 ADR 部分推翻）。

## 决定

「研究样本库」（原「探索榜」）从**提示词库的一个二级页签**升为**与提示词库并列的一级视图**。

工作台的视图结构改为两级：

```
一级视图（VIEWS，3 个）                  二级页签（LIBRARY_TABS，5 个，仅提示词库下有）
├── 提示词库    library                 ├── 快门速度
├── 研究样本库  samples                 ├── 光圈
└── 研究笔记    research                ├── 景深
                                       ├── 光线
                                       └── 艺术家 / 摄影师
```

一级视图之间**互不同类**：提示词库 = 可拼装的片段（假设集），研究样本库 = 不可拼装的成品（证据集），研究笔记 = 我自己的产出。二级页签只属于提示词库，是它的内部分类。

## 为什么难逆转

它推翻了一条**由用户明确下达的要求**（2026-11-07：「探索榜放入提示词库里面」，当时写进 ADR-0013 的修订）。这种落点一旦对外发布（深链、截图、README），改回去要付出二次沟通成本；同时它决定了 `CONTEXT.md` 的术语层级、页签计数断言的写法、以及后续第 8 / 10 步的落点。

## 理由链

| 环节 | 依据 |
| --- | --- |
| Q3 裁决 | **只有探索榜 957 条作业是社区数据**；词库 156 条是研究者自己的先验假设集。证据集与假设集**不该同层** |
| 领域模型 | 词库 = **可拼装的片段**；研究样本 = **不可拼装的成品**（`CONTEXT.md`） |
| 术语模型要防的事 | 页签「探索榜」与相邻的「快门速度」「艺术家 / 摄影师」同层，**暗示它们是同类** —— 这正是术语模型存在的意义所在 |
| 实现事实 | 探索榜自带独立筛选、独立灯箱、独立收藏、独立拆解展示 —— 它实际是一套**完整应用**，被压成了一张页签 |
| 报告 4.2 | 「要重构什么：把探索榜升为独立的一级视图，与词库并列而非从属」 |

关键点：这不是「换个位置好看」，而是把《第一性原理校验报告》4.2 节早已指出的**语义冲突在实现层闭合**。4.2 节在报告交付时（2026-11-10）就已写下这个结论，本 ADR 只是把它落成实现。

## 考虑过的选项

| 选项 | 否决理由 |
| --- | --- |
| **维持从属**：探索榜继续当提示词库的页签 | 即 2026-11-07 的落点。但它与 Q3 裁决直接冲突：证据集与假设集同层，页签标题暗示二者同类 |
| **拆成两个应用**（样本库独立成页，与工作台平级） | 工作台的左栏（会话 / 参数）跨页共享是既有价值；拆开会让样本研究丢失与当前拼装上下文的同屏关系 |
| **把提示词库降级**（两个都做二级页签，容器换名） | 换名不解决问题 —— 容器内部仍然是「假设集与证据集并列」，语义冲突原样保留 |
| **重命名但不挪位置**（仍叫「探索榜」，只是改文案） | 文案不承载层级；层级必须由结构表达 |

## 后果

- **`CONTEXT.md` 的「研究样本库」术语已更新**：明确它是**一级视图**，不是「探索榜页签」；「探索榜」作为历史称呼保留在 `_Avoid_` 里。
- **旧深链不失效**：`#explore` → `#samples` 自动重定向（`workbench.js` 的 `readHash()` + `webui/explore.html` 重定向页），**带 job 参数的深链仍能直达灯箱**。第 5 步发出去的深链继续有效。
- **二级页签的断言必须动态化**：verify 里原来的「工作台页签数与声明一致」拆成 4 条 —— 一级视图数、二级页签数、研究样本库是一级视图、二级页签里没有「探索榜」。以后加视图/加页签不用改断言。
- **ADR-0013 的落点被部分推翻**：ADR-0013 本身（探索榜是独立页面、每日采集）仍然有效 —— 被推翻的只是「它是提示词库的一个页签」这一句。该 ADR 的 2026-11-07 修订段落已标注。

## 明确不做的事

- **不改采集链与拆解链** —— 本 ADR 只管信息架构。数据从哪来、怎么拆，属第 13 步。
- **不做对照视图（2.2）** —— 并排比较 + sref 码筛选属第 8 步。
- **不引入完整键盘导航** —— 一级视图当前只覆盖左右方向键，完整导航属第 10 步的交互统一。
