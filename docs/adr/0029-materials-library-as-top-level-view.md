# 资料库升为工作台第七个一级视图（并撤销「不做导入」）

> **状态**：**partially superseded by [ADR-0030](0030-materials-library-persisted-and-baked.md)**（2026-11-13）
> **保留有效**：第七个一级视图、异质性判据、术语层、去重判据、筛选与导出边界、撤销 ADR-0022:80。
> **已被替换**：仅存储层 —— IndexedDB `mj-materials`、`blob:` 配图例外、`file://` 下可编辑。
> **决策来源**：grill-with-docs 会话第 1–2 轮 Q1–Q11 用户裁决（「共识达成，开工」）
> **配套**：`CONTEXT.md`（资料库术语层）、`docs/adr/0020-research-sample-library-is-top-level.md`（一级视图准入标准）、`docs/adr/0021-compare-view-as-top-level.md`（动作型视图先例）、`docs/adr/0022-sample-export-and-data-layer-verdict.md`（被本 ADR 撤销其中一条）、`README.md`

## 决定

新增「**资料库**」为工作台**第七个一级视图**（`#materials`），与「研究样本库」并列。它装的是**研究者自己收集、尚未成为研究证据**的提示词与图片，是一个独立数据集，不是导入表单页、不是研究样本库的一个页签、也不把数据并进研究样本库。

异质性判据（这是它能独立成视图的唯一理由）：

| | 研究样本库 | 资料库 |
|---|---|---|
| 角色 | 已入库的社区**证据** | 未经研究的**自采资料** |
| 来源 | Midjourney 探索榜每日自采（单一上游） | 来源混杂（清单 / 手工），无上游标识 |
| 成图 | 固定四格，共用同一条提示词 | 一条提示词配 **0–N 张**，可只有文字 |
| 拆解 | 有七段拆解（三态可信度） | 无拆解 |
| 身份 | 有引用键，可深链 / 观察记录 / 对照 / 导出 | 只有条目 id，不参与上述任一体系 |

一句话：**前者是「别人做出来、可以拿来做结论的成品」，后者是「我自己攒的、还没整理的原材料」。**

## 为什么难逆转

1. **它撤销了一条已 accepted 的裁决**：ADR-0022 的「明确不做的事」写有「**不做导入** —— 导入要解决冲突合并与去重，是独立的设计问题，不夹带」（`0022:80`）。本 ADR 就是那个被挂起的独立设计问题，必须留痕，否则下一个人读到 ADR-0022 还会以为导入永远不做。ADR-0022 的其余结论（尤其 `:23` 把 `file://` 双击即用升级为架构级硬约束）**继续成立**，本 ADR 不推翻它。
2. **它确立了「配图命名空间唯一」的第一个例外**：`CONTEXT.md` 与 ADR-0017 Round 16 定下全部配图统一 `../public/`，`build-webui.mjs:73-92` 与 `verify-webui.mjs:1342-1343` 是守门。资料库配图改用 `blob:` URL，是明确承担的破例；一旦对外发布截图/文档，收回去要二次沟通。
3. **它决定了术语层级与视图计数**：`CONTEXT.md` 的「工作台」定义、README 的视图列举、verify 的窄屏白名单与 `visible === N` 断言都随之改变；第 7 个视图会出现在深链与分享链接里。
4. **独立 IndexedDB 一旦有用户数据就有迁移成本**：资料库落在浏览器 profile 里，换浏览器 / 清站点数据即丢，这是本决策的固有代价，不是待修缺陷。

## 理由链

| 环节 | 依据 |
|---|---|
| Q1 裁决 | 用户选「独立数据集一级视图」而非「动作型视图」或「并入样本库」 |
| Q3 裁决 | 一条提示词 : 1–N 图、**可 0 图**、空壳卡片保留补传入口、元数据可空但保留槽位 —— 这直接坐实了与「四格成图 + 拆解」的异质性，使 (b) 站得住 |
| ADR-0020 标准 | 一级视图 = 异质的数据集；资料库与研究样本库确实异质，不属 ADR-0021 那类「动作型例外」 |
| 领域语言 | `CONTEXT.md:11` 禁用「素材库」、`:127` 禁止用「素材」指研究样本 ⇒ 正式定名「资料库」，避开禁用词，也不与「研究样本」混淆 |
| 实测约束 | `file://` 下 origin 为 `null`，浏览器写不回 `public/`；研究样本数据全部构建期内联（ADR-0003 / 0022），前端不读 JSON |
| Q5 裁决 | 保持 `file://` 双击即用 ⇒ 不引入本地服务与写接口 |

> **⚠ 部分取代提示（ADR-0030）**：本 ADR 的**存储层已被替换** —— 资料库真相源改为项目文件
> （`data/materials/` + `public/materials/`），写走本机 `/api/materials`，读走构建期烘焙的
> `webui/js/data-materials.js`；`file://` 双击只读，编辑需 `npm run dev`。
> 下文 `:45-67` 的落地与代价陈述、`:86-87` 的否决理由只作**历史记录**。

### 输入契约（Q2 / Q6）

- **清单**：JSON（数组或 `{items:[…]}`）/ CSV / Markdown。字段 `prompt`（必需）、`images`、`tags`、`author`、`note`，兼容中文表头。
- **图片按文件名匹配**：清单里的本机路径自动取 basename，用户再用文件选择器选中图片文件。理由：`file://` 下浏览器读不到任意本地路径。
- **手工录入**：提示词必填，图片可空；选中的图片文件名并入去重键，避免「同提示词 + 同图片」重复入库。
- **不做 ZIP 包** —— 引解压库只为省一次选文件，不值。

### 去重与生命周期（Q11）

判据 = **规范化提示词（去首尾 + 折叠空白 + 小写）+ 图片文件名集合（排序）**；重复**跳过**并回报条数，不做字段级合并、不覆盖。资料库与研究样本库**永久隔离**，本次不提供「提升为研究样本」通道。条目可改提示词 / 标签 / 作者 / 备注，可补传图片、删单张图、删条目（级联删 Blob，不留孤儿）。

### 配图命名空间的例外（Q7）

图片存 IndexedDB Blob，渲染时用 `URL.createObjectURL()` 生成 `blob:` URL；刷新后从库里重建。`verify-webui.mjs` 的 `offNamespace` 对 `blob:` 显式豁免。**例外不外溢**：导出的 JSON / Markdown 只带图片文件名，不含二进制；构建期「禁 `assets/`」守门原样保留。

代价明写：`blob:` URL 生命周期绑定页面会话，深链 / 导出 / 分享都带不走图片；资料库存浏览器 profile，换设备或清站点数据即丢。

### 完整交互的边界（Q4 / Q10）

| 子项 | 落点 |
|---|---|
| 网格 + 灯箱 | 复用 `.img-plate` 空态；零图条目渲染「暂无配图 · 可后期补传」 |
| 筛选 | 复用 `FILTER_ENGINE`，声明 5 维：`q` / `hasImage`（开关）/ `source`（单选）/ `tags`（多选）/ `date`（收录日单选）；URL hash 沿用 ADR-0010 |
| 已选条件条 | 逐条可移除 + 重置，不引入第二套筛选状态 |
| 备注 | 资料条目自带字段，**不复用** `research-store.js` 的 `jobKey` 外键 —— 该体系的反查只在 `EXPLORE_JOBS` 内闭合（`research-view.js:77`），资料条目没有引用键 |
| 导出 | JSON / Markdown 双格式，导出筛选命中的全量，标识用**条目 id**（不是引用键），图片只带文件名 |

## 考虑过的选项

| 选项 | 否决理由 |
|---|---|
| **动作型一级视图**（导入后并入研究样本库） | 会撞「四格成图」（`verify:534` 硬编码 4 张）与「拆解缺口归零」（`verify:169`）；导入素材没有拆解，并库后必红。让素材迁就四格定义是削足适履 |
| **不新建视图**，在样本库工具栏加导入入口 | 与 Q1 裁决直接冲突；且资料库需要自己的筛选、备注、导出与空态语义 |
| **二级页签** | `CONTEXT.md` 明确二级页签只属于提示词库，开先例会破坏层级 |
| **两段式落盘**（浏览器暂存 → 导出包 → CLI 写 `public/` → 重建） | 导入当次看不到图，与 Q3「后期手动补传图片的入口」直接矛盾 |
| **放弃 `file://`**，改本地服务 + 写接口 | 与 Q5 裁决冲突，且推翻 ADR-0022:23 的架构级硬约束 |
| **升 `mj-research` 到 v2 共用一库** | Q10 已裁定不复用观察记录外键，同库零收益，却让研究笔记的存量库经历一次版本升级 |
| **复用 `--import` CLI**（`collect-explore.ts:609-704`） | 它是「一次性导入隔壁仓存量」，会把数据并进 `config/explore.yaml`，且 `manifestToJobs` 有既知的 sref 丢失；语义与「独立数据集」不同 |

## 后果

- **ADR-0022:80 撤销，`:23` 保留** —— 导入不再是「明确不做」，但 `file://` 硬约束不变。
- **`CONTEXT.md` 新增资料库术语层**（资料库 / 资料条目 / 导入 / 收录日 / 备注 / 补传），工作台定义由「六个」改「七个」，配图命名空间补例外条款。
- **verify 的两处硬编码由 6 改 7**（`:1913` 探测白名单、`:1949-1952` 可见数）；补「资料库是一级视图」身份断言与第 11 组浏览器断言。
- **`dist/` 从 32 → 34 文件、24 → 26 个 JS**；`dist/` 仍是纯复制产物，不需手改。
- **观察记录、结论、对照、候选词条、研究样本导出的既有契约零改动** —— 资料库不进 `EXPLORE_JOBS`，因此不触发它们的引用键反查。

### 与本次改动无关的既有红，登记不代改

1. `tests/candidateVocab.test.ts` 把旧快照数字写死（971 作业 / 571 短语 / 12 精确命中 / 11 匹配），2026-11-13 采集后 `data-explore.js` 已为 **1012 条**，故 4 例失败。
2. `verify-webui.mjs` 的「拆解缺口归零」「拆解来源分层不重不漏」因 **41 条新作业无拆解** 而失败（`3+50+918+41 = 1012`）。
3. `README.md` / `docs/采集方案.md` 里的 `971 条 / 8 批次 / 20,087 张图 / dist 31 文件` 等为 11-11 旧快照数字，本次未改（不属本需求范围）。
4. `scripts/build-webui-data.mjs:107` 注释称 `pickImage` 「没有图的条目返回 null」，函数体 `:109-112` 无判空分支 —— 文档与代码不符，登记上报。

以上四项均为既有基线漂移，修它们需要单独裁决（改断言口径 vs 补跑拆解链），本 ADR 不夹带。

## 明确不做的事

- 不做七段拆解、四格补齐、对照、转研究样本、LLM。
- 不做图片 320/640 两档重编码 —— 资料库只存用户给的原始 Blob。
- 不导出图片二进制，不生成可分享的资料库深链（条目没有引用键）。
- 不引入 ZIP 解压、fake-indexeddb 或任何新依赖。
- 不改每日采集链、拆解链、`config/explore.yaml` 与 `public/` 目录结构。
