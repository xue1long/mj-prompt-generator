## 二、版本兼容矩阵

出自 [Version](https://docs.midjourney.com/hc/en-us/articles/32199405667853) 文章的 Feature Compatibility & Comparison Chart。
（官方表格里的勾叉是图片而非字符，抓取时须按图片 ID 解析：✅=`35577079214733`，❌=`35577055885197`）

| 特性 | V6 | V7 | V8.1 & V8.2 | 本工具的处理 |
|---|---|---|---|---|
| Max. Aspect Ratio | 14:1 | 14:1 | 14:1（HD 为 4:1） | 下拉补入 14:1 |
| Upscalers | Subtle & Creative | 用 V6.1 | SD 走 upscaler / HD 直接 2048px | 不涉及 |
| Pan / Zoom Out / Editor | ✅ | 用 V6.1 | 用 Edit Model | 不涉及 |
| Personalization / Moodboards | ✅ | ✅ | ✅ | `--p` 对 V6+ 开放 |
| Edit Model | ❌ | ❌ | ✅ | `--edit` 仅 V8.1+ |
| Omni Reference | ❌ | ✅ | ❌ | `--oref`/`--ow` 仅 V7 |
| Omni Reference Weight | ❌ | ✅ | ❌ | 同上 |
| Style Reference / Codes / Weight | ✅ | ✅ | ✅ | `--sref`/`--sw` 全版本；`--sv` 不含 Niji |
| Image Prompts / Image Weight | ✅ | ✅ | ✅ | `--iw` 全版本，取值范围随版本变 |
| Multi-Prompting | ✅ | ❌ | ❌ | 本工具不生成 `::` 权重语法 |
| No Parameter | ✅ | ✅ | ✅ | `--no` 全版本 |
| Quality Parameter | ✅ (0.5, 1, 2) | ✅ (1, 2, 4) | ❌ | `--q` 仅 V6/V7，选项随版本变 |
| Seed Parameter | ✅ | ✅ | ✅（99% 相同） | `--seed` 全版本 |
| Chaos / Raw / Stylize / Tile / Weird | ✅ | ✅ | ✅ | 全版本 |
| `--exp` Parameter | ❌ | ✅ | ✅ | 仅 V7+ |
| Niji Version | ✅ `--niji 6` | ✅ `--niji 7` | ❌ | 版本下拉含 Niji 6/7；Niji 与 V8 不兼容 |
| Draft Mode | ❌ | ✅ | ❌（见下方矛盾登记） | 保留 V7 + V8.1/8.2 |
| Relax Mode / Fast Mode | ✅ | ✅ | ✅ | `--relax`/`--fast` 全版本 |
| Turbo Mode | ✅ | ✅ | ❌ | `--turbo` 仅 V6/V7 |

**版本沿革**：V7 于 2025-04-03 发布，2025-06-17 ~ 2026-06-09 为默认；V8.1 于 2026-04-14 发布，2026-06-10 ~ 07-23 为默认；**V8.2 于 2026-07-24 成为当前默认版本**。V8.0 是 alpha，已于 2026-07-24 停用。Niji 7 于 2026-01-09 发布。

## 三、参数取值明细

| 参数 | 官方取值 | 官方默认 | 出处 |
|---|---|---|---|
| `--ar` | 不得含小数，上限 14:1（HD 为 4:1） | 1:1 | Aspect Ratio 文章 |
| `--s` | 0–1000 | 100 | Stylize 文章 |
| `--c` | 0–100 | 0 | Chaos 文章 |
| `--weird` | 0–3000 | 0 | Weird 文章 |
| `--sw` | 0–1000 | 100 | Style Reference 文章 |
| `--sv` | V6 为 1–4，V7 为 1–6 | V6 为 4，V7 为 6 | Style Reference 文章 |
| `--iw` | V7/V8.1 为 0–3，Niji 7 为 0–2 | 1 | Image Prompts 文章 |
| `--ow` | 1–1000 | 100 | Omni Reference 文章 |
| `--q` | V6 为 0.5/1/2，V7 为 1/2/4（V7 没有 `--q 3`，写了会自动切到 `--q 4`） | 1 | Quality 文章 |
| `--seed` | 0–4294967295 | — | Seeds 文章 |
| `--raw` | V5.1 及以后支持 | 关 | Raw 文章 |
| `--exp` | **官方无专页**，仅在版本兼容表确认 V7+ | — | 见下方"无官方出处的结论" |
| `--oref` | 只能带一张图；GPU 时间 2 倍 | — | Omni Reference 文章 |
| `--edit` | 最多 4 张参考图；V8.1/V8.2 | — | Edit Model 文章 |
| `--hd`/`--sd` | 2048px / 1024px | SD | Version 文章 |
| `--p` | V6 及以后 | — | Personalization 文章 |
| `--sw` / `--sv` | 与 Moodboards 不兼容 | — | Style Reference / Moodboards 文章 |

裁决顺序：专页 > 汇总表 > 最新更新 > changelog > 二手。

## 六、已从上游移除的参数

| 上游参数 | 移除理由 |
|---|---|
| `--stop` | 官方现行参数表中**不存在**；上游代码有分支但 YAML 无配置项，原本就是永不生效的死代码 |
| `--style`（`raw` / `original`） | 官方现行写法是 `--raw`（Raw 文章）；`--style original` 属 V1–V4 时代遗留 |
| `--cref` | 官方 Legacy 参数，V7 起由 Omni Reference 取代，V8.1 起由 Edit Model 取代 |

## 七、本工具与官方的两处有意偏差

| 项 | 官方 | 本工具 | 理由 |
|---|---|---|---|
| `--ar` 默认值 | 1:1 | 16:9 | 摄影场景更常用；这是产品选择，不是事实错误。面板说明里已注明官方默认值 |
| 版本下拉 | 未列 5.x | 只列 V8.2 / V8.1 / V7 / V6.1 / V6.0 / Niji 7 / Niji 6 | 官方现行文档只覆盖 V6 以后与 Niji 6/7，5.x 属 Legacy，无权威兼容矩阵可依 |
