# 采集方案

> **定位**：本文件是**现状说明 + 操作手册**，汇总「研究样本库」与「风格榜」两条采集链的数据源、命令、产物、失败策略、本机调度与验证方式。
> **权威边界**：本文件**不是裁决记录**。架构决策以 `docs/adr/` 为准，领域语言以 `CONTEXT.md` 为准，功能口径以 `README.md` 为准。与它们冲突时以那三处为准，差异登记在第 6 节，不在此处擅自改写。
> **落盘日期**：2026-11-12（含当日计划任务注册与试跑结果）

## 0. 一句话结论

| 链 | 形态 | 调度 |
|---|---|---|
| **研究样本库**（原探索榜） | 匿名接口每日自采 → 两档配图 → YAML 快照 → 烘焙 → 构建 | **已挂 Windows 计划任务**，每日 15:00，仅用户登录时运行 |
| **风格榜**（styles_top） | 码清单固定 200 个 → 匿名 CDN 下 8 题材图 → 扫本地图生成 YAML | **无自动调度**；榜单变动须人工 `--capture`（需已登录 Chrome 9222） |

仓库里此前没有独立的采集方案文档，方案分散在 ADR-0013、ADR-0018、README 两节与源码注释中。本文件把它们收拢到一处，并补上本机调度与排障记录。

### 2.2 唯一入口：四步固定顺序

`scripts/update-explore.mjs` 是**唯一入口**（ADR-0017 Round 11）。不用 `&&` 链，因为「分解失败不阻断」用 shell 表达不了。

| 步 | 做什么 | 失败后果 | 出处 |
|---|---|---|---|
| 1 采集 | `tools/collect-explore.ts` → 写 `config/explore.yaml` + 下图 | **致命**：旧快照与旧图保留 | `update-explore.mjs:103-109` |
| 2 分解 | `tools/decompose-explore.ts`（需 LLM 代理 / `.env`） | **只告警不阻断**；派生文件先备份、失败回滚 | `update-explore.mjs:76-100,118-140` |
| 3 烘焙 | `scripts/build-webui-data.mjs`：`config/*.yaml` → `webui/js/data-*.js` | **致命**：中止，不更新 `dist/` | `update-explore.mjs:143-146` |
| 4 构建 | `scripts/build-webui.mjs`：`webui/` → `dist/` | **致命** | `update-explore.mjs:149-152` |

`build-webui-data.mjs:56-59` 强制读 `explore.yaml` / `explore-decomposed.yaml` / `styles-top.yaml` 三份，缺一即中止（`:86-88`）。

```powershell

```

### 3.1 `.bat` 的格式约束（本次踩坑，改动前必读）

`更新探索榜.bat` 必须是 **GBK(cp936) 编码 + CRLF 换行**。原因：计划任务启动的 `cmd.exe` 用系统 ANSI 代码页（中文 Windows = 936）逐行解析批处理；若文件是 UTF-8 无 BOM，中文注释的多字节序列会与下一行的 ASCII 命令字符错误组合，把 `REM` / `echo` / `if` 的命令前缀吃掉，表现为 `'EM' is not recognized as an internal or external command`，`npm` 从未启动，任务返回 1。**LF-only 换行同样不可靠**。

检测命令（应得到 `CRLF=25 LF_ONLY=0 VALID_UTF8=false`）：

```bash
node -e "const b=require('fs').readFileSync('更新探索榜.bat'),s=b.toString('latin1');console.log('CRLF='+(s.match(/\r\n/g)||[]).length,'LF_ONLY='+(s.match(/(?<!\r)\n/g)||[]).length,'VALID_UTF8='+Buffer.from(b.toString('utf8'),'utf8').equals(b))"
```

原始 UTF-8/LF 版本已备份在 `node_modules/.cache/mj-pretrial/更新探索榜.bat.utf8lf.bak`（不入库）。

## 4. 2026-11-12 试跑验证记录

用户授权「注册后立即试跑一次」。过程**不是一次成功**，如实记录：

| 轮次 | 结果 | 判定 |
|---|---|---|
| 1 | `LastTaskResult=1`，21 秒返回 | 产物时间戳全未变、无 npm 日志 ⇒ 失败在解析阶段，非采集 |
| 2 | 加日志重定向后仍 1，日志文件都没生成 | Action 的 `/c ""…bat""` 过度引号形式有问题 |
| 3 | 极简探针 `echo PROBE_OK > …` 得 `0` 且写出文件 | **排除**任务本身 / Interactive 登录 / 写权限问题 |

| 5 | 前置 `chcp 65001` 得 `0` 但日志仍报解析错误 | **假绿**：退出码 0 不代表链路跑通，改看日志与产物 |
| 6 | 转 GBK + CRLF、Action 去掉 chcp，得 **0** | 四步全跑完，日志 3,051 字节，产物更新 ⇒ 通过 |

**已知缺口**（均未在本文件之外做改动，处理与否由项目所有者决定）：

2. **`.env` 由 webui 顶栏设置面板配置**（2026-11-13 起）：项目根 `.env`（UTF-8、无 BOM，`.gitignore:56` 忽略、绝不入库）的 `MJ_DECOMPOSE_BASE_URL / API_KEY / MODEL` 三项，可点顶栏设置面板「LLM 代理设置」保存写入 —— **需 `npm run dev`**（`scripts/serve-webui.mjs` 只绑 127.0.0.1，提供受限 `GET/POST /api/settings`）；直接双击 `file://` 打开 webui 时面板降级为只读，提示改用 `npm run dev`。**面板写入的就是计划任务读取的同一份根 `.env`**：`MJ-Explore-Daily` 每日 15:00 无人值守读它做第 2 步分解，故此处必须是长期有效的静态凭据，不能填会话级临时 token。**不要填占位假值**：`decompose-explore.ts:105-117` 只判非空，占位假值会伪装成「已配置」，转而拿不可达地址跑完全部失败、且日志不再提示缺配置。三项留空期间每天第 2 步仍固定失败并告警（不阻断），新增样本走灯箱空态；`--dry-run` 实测增量待分解为 21 条，不会触发 992 条全量重算。填完后按 `node tools/decompose-explore.ts --limit 1` 小批验证连通与严格 JSON，再 `npm run build:webui-data && npm run build`。
3. **日志可观测性**：`logs/explore-task.log` 每次覆盖、无按日归档、中英混合编码；`LastTaskResult=0` 曾出现「假绿」，判断成功必须同时看日志与产物时间戳。
4. **单图失败口径**：`collect-explore.ts:780-790` 中单图两次重试失败只打日志、仍写快照，与 README「失败即中止、页面不开天窗」的口径不完全一致（后者覆盖的是接口/写快照层）。
5. **文档漂移**：① ADR-0013:33 写「Node 为主通道、curl 兜底」，实际 `collect-explore.ts:26-27` 统一走 `curl.exe`；② ADR-0018 引用的 `StylesTopLibrary.vue` / `src/types/styleTop.ts` 已随 Vue 删除（ADR-0023），现为 `webui/js/styles-top-view.js`（ADR-0026）；③ `config/styles-top.yaml:2-3` 头注释仍写「从隔壁仓生成」，实际默认走本地预览图目录（`build-styles-top.ts:167`），是 `renderStylesTopYaml` 硬编码的旧 header。

## 7. 排障与回退

### 7.1 任务跑挂了先看三处

| 检查 | 判据 |
|---|---|
| 退出码 | `Get-ScheduledTaskInfo -TaskName 'MJ-Explore-Daily' \| Select LastRunTime,LastTaskResult` —— **0 不等于成功**，曾出现假绿 |
| 运行日志 | `logs/explore-task.log` 是否有四步标题（`1/4 … 4/4`）、`[collect-explore] 完成`、末尾 `完成。dist\index.html 已更新。` |
| 产物 | `config/explore.yaml` 的 `generatedAt` 是否变成当天；`webui/js/data-explore.js` mtime 是否更新。没变就是采集没落地 |

常见原因：Cloudflare / 网络被拦（重试即可，旧快照保留）；`.bat` 被改回 UTF-8 或 LF（见 3.1）；`.env` 三项未配置或 LLM 代理不可达（可经 webui 顶栏设置面板配置，见缺口 2；第 2 步只告警、不算整体失败）；任务在用户未登录时不会运行（Interactive 设定）。

### 7.2 回退

```powershell
# 1) 注销计划任务
Unregister-ScheduledTask -TaskName 'MJ-Explore-Daily' -Confirm:$false
```

```bash
# 2) 恢复 .bat 到原始 UTF-8 / LF（若需撤销本次格式修复）
node -e "require('fs').copyFileSync('node_modules/.cache/mj-pretrial/更新探索榜.bat.utf8lf.bak','更新探索榜.bat')"

# 3) 恢复试跑前的探索榜快照（随后重跑烘焙 + 构建）
node -e "require('fs').copyFileSync('node_modules/.cache/mj-pretrial/explore.yaml.bak','config/explore.yaml')"
npm run build:webui-data && npm run build
```

`public/explore/` 与 `dist/` 都是生成物，回退快照后重跑构建即可；`public/explore/` 里本次新下的 84 组图不影响旧快照（旧作业引用旧图）。
