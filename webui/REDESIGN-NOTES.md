# MJ Prompt Generator — WebUI 重设计说明

对 `E:\002-Pr\011 - Midjourney\MJ Prompt Generator` 做的一次界面重做。
本目录是可交互的高保真原型（纯静态 HTML/CSS/JS，无构建步骤，双击 `index.html` 即可打开）。

---

## 1. 原实现读到了什么

- **技术栈**：Vue 3 + Naive UI + Pinia，Vite 构建；配置以 YAML 静态内联进产物。
- **结构**：`App.vue` 恒定两栏 —— 左「会话 Dock」（已选提示词 / 主体与环境 / 最终提示词 / 参数），右「提示词库」（9 个页签，末位是探索榜）。
- **领域约定**（来自 `CONTEXT.md` 与 `docs/adr/`）：最终提示词按 **摄影前缀 → 机位 → 主体环境 → 光线 → 其他 → 参数** 拼装；参数与模型版本有兼容关系且写在 YAML 里；「手动编辑提示词」与自动提示词并存直到重置；探索榜的「作业」是社区成品，不能拼进提示词。
- **界面上的实际痛点**：顶栏渐变底 + 一排 emoji 图标；「主体与环境」标题重复出现两次；左栏四张卡片各占一格、大量空白；最终提示词被挤在参数折叠区上方；右栏页签条第一个页签被裁掉；卡片套卡片。

## 2. 这次改了什么

### 视觉系统：暗房仪表盘
- 冷石墨中性底（不用暖米色）—— 让摄影作品成为画面里唯一的暖色。
- **单一琥珀强调色**替代原来的绿色，用途严格限定为：选中 / 激活 / 主操作 / 焦点。
- 冷钢蓝作领域次强调，只用于槽位标识、`--sref` 与参数值。
- 衬线 display（Iowan Old Style + 宋体系回退）只出现在品牌字、页面标题、艺术家姓名；界面正文系统 sans；提示词、参数、计数一律等宽。
- 明暗双主题，token 驱动，`mj-theme` 落盘。

### 信息架构
- 会话 Dock 常驻四个屏（沿用 ADR-0016 的核心主张：切换不重挂、不换栏）。
- **已选提示词按拼装槽位分组**（艺术家 / 机位 / 光线 / 其他），组内顺序即最终提示词里的位置 —— 这是原实现没有做、但代码里已经定义了的结构。
- 最终提示词做成**常驻底部的输出条**，带参数尾视觉分离、字符数、复制 / 改写 / 清空。
- 参数做成**版本感知的折叠面板**：当前模型版本下不可用的参数显示为「不可用」并从提示词中剔除，与 YAML 的 `versions` 字段一致。

### 交互
- 选词、排序、删词、参数调整全部实时重算最终提示词。
- 手动改写版与自动版并存：改写后显示「已手动改写」，可继续改或一键回到自动。
- `⌘K / Ctrl K` 全局搜索：同时检索词条、艺术家、风格码，命中即可直接取用。
- 会话状态落盘 `mj-session-v2`，刷新与跨屏不丢。
- 深链：`index.html#artists`、`#shutter-speed` 等直接落到某个分区。

### 探索榜
- 作业网格 + 批次 / 比例 / 只看有 sref 筛选。
- 灯箱里给七段拆解（主体 / 动作状态 / 细节环境 / 构图镜头 / 光线色彩 / 风格审美 / 参数尾）、命中构图法、词库打标与合规体检，逐条落位。

## 3. 探索榜：回到提示词库里的页签

原实现把探索榜放在提示词库的第 9 个页签（ADR-0013）。
中途我把它提为一级导航，理由是「四格成图需要整幅画布」—— 这个理由站不住：
工作台右栏在 1440px 下有约 980px，与艺术家网格（每卡 245px）是同一密度，
塞进去仍然是 4 列，并不比独立页差；而提为一级导航等于推翻了 ADR-0013。

现已改回：**探索榜是工作台提示词库的第 6 个页签**，与四个摄影词库分类、艺术家并列。
会话 Dock 依然常驻、只换右栏（ADR-0016）。

- 页签条：快门速度 / 景深和光圈 / 镜头的长短和位置 / 光线控制 / 艺术家·摄影师 / 探索榜。
- 切到探索榜时，右栏页头换成「探索榜 + 说明 + 作业计数」，工具条换成批次 / 比例 / sref 筛选。
- 深链 `index.html#explore` 可直达。
- 顶栏导航回到「工作台 / 画廊 / 风格库」三项。
- `explore.html` 保留为旧链接的落点，跳到 `index.html#explore`。

## 7. 交付前打磨（第二轮）

这一轮只做「能上生产」的修正，不改视觉方向。

**可访问性**
- 顶栏加跳过链接；页签组补全 `tablist` / `tab` / `tabpanel` 语义、`aria-selected`、漫游 tabindex 与左右方向键。
- 弹层统一走 `mountDialog()`：`role="dialog"` + `aria-modal` + Esc 关闭 + Tab 焦点陷阱 + 关闭后焦点归还原触发元素。搜索面板与探索榜灯箱共用。
- 所有表单控件补可读名称（主体与环境、各参数控件、搜索框）；开关类控件用 `aria-pressed` 表达状态。
- toast 与筛选计数用 `role="status" aria-live="polite"`，读屏能听到「已复制」「N 条匹配」。
- 表单控件的焦点环此前被 `:focus { outline: none }` 吃掉，已补回；图标按钮命中区用伪元素扩到 ≥44px；触屏设备下按钮最小高度 44px。

**对比度**
- 亮色主题的 `--muted` 由 52% 降到 46%、`--accent` 由 55% 降到 50%（小字号文本原来不足 4.5:1）。
- 新增 `--control-border`：输入框描边与所属面达到 ≥3:1，不再只靠一条淡线。

**状态**
- 空状态做成统一组件（图标 + 标题 + 说明），替代一行灰字。
- 数据模块没加载成功时不再白屏：显示错误面板与「重新加载」。
- 图片有加载微光与「图片不可用」的失败占位。

**响应式**
- 工具条与按钮行改为可折行；统计徽章不折行且整组可换行——修掉了窄屏的横向溢出。
- ≤1080px 时顶栏搜索收成图标按钮；横向导航条不露滚动条。
- ≤980px 单栏：浏览区在前（沿用原产品的小屏优先级），最终提示词条改为固定在视口底部，会话区高度封顶。

**其他**
- 「实测」角标在整页皆实测时改为写进小标题，去掉逐卡贴标。
- 画廊与探索榜网格密度调高（各多一列），浏览更快。
- 折叠面板去掉浏览器默认三角，改用会转的箭头。

## 8. 第三轮：按上一轮的建议执行

**小屏的 DOM / 视觉顺序倒置已消除**

上一轮我说「把 `<aside id="dock">` 挪到 `<main>` 之后并反转宽屏的 `order`」——这个建议只对了一半：
那样做会把倒置从窄屏搬到宽屏，而宽屏是主要使用场景，键盘用户要越过整个浏览区才能 Tab 到「复制提示词」。

最终做法是**任何断点下 DOM 顺序都等于视觉顺序**，代价是窄屏会话区排在浏览区之前：

- 宽屏：左会话 Dock + 右浏览区（DOM 同序，键盘顺序正确）。
- 窄屏：不再用 CSS `order` 倒置，会话区在上、浏览区在下；会话明细（已选提示词 + 参数）
  收进一个折叠块，摘要写着「已选 N 条 · 参数 M 项」，点开才展开。最终提示词条仍固定在视口底部。

**艺术家与风格码改为全量索引 + 按需取图**

- 艺术家 4,322 条、风格参考码 4,638 条全部进本地索引（名字、分类、分面词、主色、简介、风格描述）。
- 参考图按需取：本地带了图的出照片；取不到图的落回排版版位（艺术家写名字，风格码写码号）。
  图片加载失败时也会自动降级到同一个版位，所以这套逻辑搬到 CDN 上原样可用。
- 分面计数、分类计数、「只看实测」计数现在都是全量真实数字（实测 458 条、画家 1,546 条…）。
- 艺术家与风格码各加了一个详情弹层：简介、风格描述、分面词、主色、上游链接，可直接「加入提示词」。

**探索榜抽成可复用组件**

`js/explore-board.js` 导出 `headHtml / toolbarHtml / bodyHtml / wire` 四段，
工作台按页签拼装，独立的 `explore.html` 也复用同一套。

- `js/workbench.js`：页签表新增「探索榜」（计数 942，与艺术家 4,322 同为真实词库规模）；
  渲染时按页签切换页头、工具条与内容区；探索榜页签下工作台自己的工具条不出现。
- `js/explore-board.js`：由「整页渲染」改为「三段式 + 接线」，供工作台与独立页各自拼装。
- `js/core.js`：顶栏导航去掉「探索榜」，回到 工作台 / 画廊 / 风格库。
- `explore.html` 改为跳转到 `index.html#explore` 的落点页；`js/explore.js` 删除。
- 复审：工作台的「艺术家」与「探索榜」两个页签均 **可访问性 100 / 最佳实践 100**。

## 9. 第四轮：Lighthouse 自动审计

本机其实装了 Chrome（v156），之前是我的检测脚本用未展开的环境变量拼路径才误报「未安装」。
接上浏览器工具后跑了一遍 Lighthouse（snapshot 模式，四屏 + 亮色主题 + 移动端视口）：

| 屏 | 可访问性 | 最佳实践 |
|---|---|---|
| 工作台（暗色 / 亮色 / 移动端视口） | 100 | 100 |
| 探索榜 | 100 | 100 |
| 画廊 | 100 | 100 |
| 风格库 | 100 | 100 |

自动审计揪出并已修掉四处：

1. **分面按钮的 `aria-controls` 指向不存在的节点** —— 分面面板关闭时并未渲染，
   `aria-controls="facet-panel"` 因此无效。改为只在面板展开时才输出该属性。
2. **选中页签上的计数对比度只有 3.79:1** —— 选中态底色偏暖，`--muted` 压不住了。
   选中态的计数改用 `--fg-2`。
3. **探索榜作业卡的 `aria-label` 与卡面可见文字不匹配**（axe: label-content-name-mismatch）
   —— 去掉 `aria-label`，让标题、比例、版本、作者这些可见文字直接构成无障碍名。
4. **风格码卡的同类问题** —— `aria-label` 换成 `title`（鼠标提示），可见文字作无障碍名。

另外按 Chrome 的表单提示给 24 个参数控件补齐了 `id` 与 `name`，并给四屏补了 `meta description`。

仍未通过的只有 `robots.txt` 与 `llms.txt` 两项 —— 它们是「公开网站」的部署产物，
本地工具原型没有公开地址，加这两个文件只是刷分，没有意义。
